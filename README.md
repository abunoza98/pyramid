# Football Pyramids

footballpyramids.com: Europe's top five leagues on the home page, and a full pyramid page for each country (England, Spain, Germany, France, Italy). Three or four tiers per country, with regional groups where a tier is split.

## What's here

| File | What it does |
| --- | --- |
| `index.html`, `england/`, `spain/`, `germany/`, `france/`, `italy/` | The pages. Generated by `scripts/build.mjs`, so don't edit them by hand. |
| `assets/style.css` | The look of every page. |
| `assets/render.js` | Turns the data into tables. Used by the build and by the browser when tables refresh. |
| `assets/app.js` | Club finder, remembered club, and refreshing the tables every 5 minutes. |
| `data/<country>.json` | The tables. Currently a hand-gathered snapshot (`"mode": "snapshot"`). |
| `data/clubs.json` | Every club and its league, for the club finder. Generated. |
| `scripts/leagues.mjs` | The settings for every country and league: API IDs, promotion/relegation zones, notes, club-name fixes. |
| `scripts/update-standings.mjs` | Pulls fresh tables from API-Football, writes the data files and rebuilds the pages. |
| `scripts/build.mjs` | Rebuilds the pages, sitemap and robots.txt from the data files. |
| `.github/workflows/update-standings.yml` | Runs the updater on GitHub every hour through the day. |
| `test/api-football-sample.json` | A sample API response for testing without a key. |

## Changing something

- **A zone or note is wrong** (say a league changes its play-off places): edit `scripts/leagues.mjs`, then run `node scripts/build.mjs`.
- **A club name looks odd** after a live update: add it to `NAMES` in `scripts/leagues.mjs`.
- **Adding a league or a tier:** add it to the country's `leagues` list in `scripts/leagues.mjs` with its API-Football ID, then run the updater.

## Going live with real data

1. Upgrade to API-Football **Pro** (the free plan can't see the current season).
2. Run `API_FOOTBALL_KEY=yourkey node scripts/update-standings.mjs --check`. It lists each country's leagues with their IDs. Check the IDs in `scripts/leagues.mjs` match, especially **Ligue 3**, which is new this season.
3. Run `API_FOOTBALL_KEY=yourkey node scripts/update-standings.mjs` once and look at the pages (`npx serve .`, then http://localhost:3000). Fix any odd club names.
4. On GitHub, add the key under Settings → Secrets and variables → Actions as `API_FOOTBALL_KEY`, and upload `.github/workflows/update-standings.yml`.

## Testing without a key

```
node scripts/update-standings.mjs --fixture test/api-football-sample.json --out /tmp/fp-test
```

## Things to know

- **Request budget.** 16 leagues per run, 14 runs a day = 224 requests. Pro allows 7,500.
- **"Live" means within about an hour.** API-Football refreshes standings hourly.
- **Points deductions.** The API has no deduction field, so the updater works them out from wins, draws and points and adds a note under the table.
- **No crests.** API-Football's docs say club logos may need permission from the clubs or leagues. The site shows names only.
